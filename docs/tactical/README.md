# Implementation Tactical Docs

Bounded implementation plans and execution records live here.

Use zero-padded numeric prefixes for new tactical docs: `000-topic.md`,
`001-next-topic.md`, and so on. Keep one active implementation slice per doc.
Parent sequencing checklists are allowed when they keep a related series
focused; mark them clearly as parent docs and add every new tactical to this
index.

For vanilla behavior and visual correctness, use
`../../reference/minecraft-1.17.1/src/` first. That includes renderer-facing
behavior such as model baking, texture atlas stitching, mipmap/filter state,
light texture math, fog, sky, render layers, particles, and section traversal.
For platform and renderer-boundary mechanics, performance tooling, Android, or
XR tacticals, use the sibling Playbox repo at `~/code/playbox` as a pattern
library after the Java behavior is understood. Start with
`~/code/playbox/Cargo.toml`, `docs/architecture/rendering.md`,
`docs/architecture/platforms.md`, `android/README.md`, and
`android-xr/README.md`. Mclone's Rust `profile.dev` is optimized at
`opt-level = 2`, following Playbox, so debug movement/render smokes are less
misleading while still retaining debug assertions.

For durable subsystem progress indexes, see
[`../topics/`](../topics/README.md). In particular, current performance priority
lives in [`../topics/performance.md`](../topics/performance.md), and current
lighting progress and next solver/status/rendering slices live in
[`../topics/lighting.md`](../topics/lighting.md). The tactical docs below remain
the detailed implementation records.

**Active render-residency direction:** native and web share the
`RenderSectionCompiler` contract while retaining native channel payloads and
the browser resident `SharedArrayBuffer` ring. The chunk-based synthetic Far
LOD experiment built by Tacticals 121/162/166/172 is now rejected as the
multi-kilometer product architecture. Tactical
[`245`](245-retire-chunk-far-lod-runtime.md) removes that complete vertical
feature and strips its specializations from the still-useful real-section
worker, budget, and upload machinery. Terrain Lab and
[`../topics/gpu-procedural-terrain.md`](../topics/gpu-procedural-terrain.md)
own the evidence for any later multiscale in-game replacement. Current
retirement status lives in [`../topics/far-lod.md`](../topics/far-lod.md).
The preferred toroidal replacement direction now lives in
[`../topics/procedural-horizon-clipmap.md`](../topics/procedural-horizon-clipmap.md);
shared map/orbit controls and the standalone Explorer product live in
[`../topics/world-view-navigation.md`](../topics/world-view-navigation.md).
