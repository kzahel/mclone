# Contributing

This is a WIP side project with limited gameplay and experimental terrain and
rendering systems. Project licensing is still TBD; no project license has
been selected. Existing third-party notices remain applicable.

For a bug report, include the platform/device, build revision or nightly,
reproduction steps, expected and observed behavior, and relevant logs. A
small reproduction and a screenshot help with rendering or input issues.
Avoid posting credentials, private endpoints, or local Minecraft assets.

Discuss substantial changes before investing in them. Keep shared gameplay
and engine behavior in the shared Rust crates, and platform glue in the app
adapters. Follow [the development guide](docs/development.md) for setup and
[the platform guide](docs/platforms.md) for affected validation lanes.
